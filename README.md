# VegTrack — ระบบทำนายอายุการเก็บรักษาผักสดด้วย AIoT

**micro:bit Thailand Challenge 2026 · รุ่น S2 AIoT & Data Collection**
ทีม BUZZA11DAY | โรงเรียนบางละมุง

VegTrack ติด micro:bit + DHT22 ในลังผัก เพื่อวัดสภาพแวดล้อมระหว่างขนส่ง
จำแนกเหตุการณ์ (กระแทก/ถนนขรุขระ/ยกขนถ่าย ฯลฯ) ด้วย Edge AI บนบอร์ด
แล้วคำนวณเกรดความสด A/B/C จากสมการที่สอบเทียบจากการทดลองจริง
ส่งผลขึ้น Google Sheets ให้ผู้ขายจัดลำดับการขายก่อน–หลังได้ถูกต้อง (First Expire First Out)

---

## โครงสร้างโปรเจกต์

```
vegtrack/
├── board-a/            โค้ด micro:bit ตัวส่ง — ติดในลังผัก (JavaScript, MakeCode)
├── board-b/            โค้ด micro:bit ตัวรับ — วางที่ร้าน (JavaScript, MakeCode)
├── model/              สมการอ้างอิง (Python) สำหรับทดสอบ/อธิบายนอกบอร์ด
└── docs/                เอกสารประกอบ (ที่มาของสมการ, ผลการทดลอง)
```

## ระบบทำงานอย่างไร

```
[DHT22 + Edge AI]  --Radio-->  [Board A]  --Radio-->  [Board B]  --USB-->  [คอมพิวเตอร์ / Google Sheets]
```

1. **Board A** (ติดในลัง, ใช้แบตเตอรี่, ไร้สาย) — อ่าน DHT22 ทุก ~4 วินาที, จำแนกเหตุการณ์ด้วยโมเดล Edge AI ที่ฝึกด้วย micro:bit CreateAI (5 คลาส: นิ่ง / ถนนเรียบ / ถนนขรุขระ / ยกขนถ่าย / กระแทก), คำนวณเกรดจากสมการ, ส่งผลผ่าน Radio
2. **Board B** (วางที่ร้าน, เสียบ USB, ไม่โดนกระแทก) — รับข้อมูลจาก Radio แล้วส่งต่อออก Serial ให้คอมพิวเตอร์นำไปใช้ต่อ (เช่น อัปขึ้น Google Sheets)

## สมการ (สรุปย่อ — รายละเอียดเต็มใน `docs/equation.md`)

```
อัตราการสูญเสียน้ำหนัก (%/วัน) = 0.1685 x อุณหภูมิ(°C) + 4.2172
อายุที่เหลือ (วัน) = (% น้ำหนักคงเหลือ − 80) / อัตราการสูญเสียน้ำหนัก

เกรด A: อายุที่เหลือ >= 1.5 วัน
เกรด B: อายุที่เหลือ 0.5–1.5 วัน
เกรด C: อายุที่เหลือ < 0.5 วัน
```

สมการนี้สอบเทียบจากการชั่งน้ำหนักและให้คะแนนความสดคะน้าจริง 8 มัด ต่อเนื่อง 4 วัน
ทดสอบด้วย holdout samples ได้ **MAE = 0.25 วัน**

**จำนวนกระแทกที่ Edge AI ตรวจจับได้ ไม่ได้เข้าสมการ** — ทดสอบแล้วพบว่ากลุ่มที่โดนกระแทกไม่ได้เสียเร็วกว่ากลุ่มควบคุม (Penalty ที่คำนวณได้ติดลบ) จึงแสดงเป็น "ดัชนีความบอบช้ำ" แยกต่างหากให้ผู้ขายดูประกอบการตัดสินใจแทน

## เริ่มใช้งาน

### Board A / Board B (micro:bit)
1. เปิด [makecode.microbit.org](https://makecode.microbit.org) → สร้างโปรเจกต์ใหม่
2. เพิ่ม extension: **DHT11_DHT22** (`alankrantas/pxt-DHT11_DHT22`) และฝึกโมเดล **Edge AI** ด้วย micro:bit CreateAI (5 คลาส: Still, SmoothRoad, RoughRoad, Lift, Impact)
3. สลับไปแท็บ **JavaScript** (มุมขวาบน) แล้ววางโค้ดจาก `board-a/main.js` หรือ `board-b/main.js` ทับของเดิม
4. ต่อ DHT22 เข้าบอร์ด A: `VCC → 3V`, `GND → GND`, `DATA → P1`
5. Flash ลงบอร์ดตามลำดับ (A ก่อน แล้วค่อย B) — `radio.setGroup()` ต้องเป็นเลขเดียวกันทั้งสองบอร์ด

### Model (ทดสอบสมการแยกนอกบอร์ด)
```bash
python model/vegtrack_model.py
```

## ผลการทดลอง

| สมมติฐาน | ผลลัพธ์ |
|---|---|
| H1: การกระแทกทำให้ผักเสื่อมเร็วขึ้น | **ไม่พบหลักฐานสนับสนุน** — กลุ่มกระแทกไม่ได้เสียเร็วกว่ากลุ่มควบคุม |
| H2: %น้ำหนักที่ลดสัมพันธ์กับคะแนนความสด | **สนับสนุน** — ทุกกลุ่มลดไปทิศทางเดียวกันตลอด |

**Edge AI (Experiment 1):** ทดสอบ validation 25 ตัวอย่าง (5 คลาส × 5 ครั้ง) จำแนกถูก 25/25

## ข้อจำกัด

- สอบเทียบจากอุณหภูมิเพียง 2 ระดับ (~30°C และ ~9°C) — สมการเส้นตรงยังไม่ได้ยืนยันที่ช่วงกลาง
- บนบอร์ดไม่มีเซนเซอร์ชั่งน้ำหนัก ใช้การประมาณจากอุณหภูมิสะสมแทน
- ทดลองกับคะน้าล็อตเดียว 8 ตัวอย่าง — การใช้กับผักชนิดอื่นต้องสอบเทียบค่าคงที่ใหม่

## แผนต่อยอด

- สะสมข้อมูลผ่าน Google Sheets ต่อเนื่อง เพื่อฝึกโมเดล ML ทำนาย shelf life ที่แม่นยำขึ้น
- ขยายไปผักใบชนิดอื่นและผลไม้ที่ช้ำง่าย (มะม่วง, สตรอว์เบอร์รี)
- เพิ่มโมดูล LoRa สำหรับระยะส่งข้อมูลที่ไกลขึ้น
- ใช้ Hash Chain ป้องกันการแก้ไขข้อมูลย้อนหลัง สำหรับกรณีส่งออก
