# 🥬 VegTrack

**ระบบติดตามความสดของผักหลังการเก็บเกี่ยวแบบเรียลไทม์** ด้วยเซนเซอร์บน micro:bit เชื่อมต่อผ่าน USB Serial เข้ากับแดชบอร์ดที่รันบนเครื่องคอมของเราเอง — ไม่ต้องพึ่งอินเทอร์เน็ตหรือเซิร์ฟเวอร์ภายนอกก็ใช้งานได้

โปรเจกต์นี้ทำโดยทีม **BUZZA11DAY** เพื่อแก้ปัญหาการสูญเสียผักหลังเก็บเกี่ยว โดยการเฝ้าดูอุณหภูมิ ความชื้น น้ำหนักที่หายไป และแรงกระแทกระหว่างขนส่ง แล้วแปลงเป็น "เกรดคุณภาพ" และ "จำนวนวันที่เหลือก่อนผักจะเสีย" ให้คนหน้างานตัดสินใจได้ทันทีว่าล็อตไหนต้องรีบขาย ล็อตไหนยังรอได้

## ✨ ฟีเจอร์หลัก

- **แดชบอร์ดเว็บแบบเรียลไทม์** — ธีมสว่าง ทันสมัย อ่านง่าย พร้อมฟอนต์ไทยคุณภาพสูง (Noto Sans Thai) อัปเดตข้อมูลอัตโนมัติทุก 2 วินาที
- **รองรับหลายล็อตพร้อมกัน** — เสียบ micro:bit ได้หลายตัว เทียบสถานะแต่ละล็อตในหน้าเดียว พร้อมจัดลำดับล็อตที่ต้องรีบขายไว้บนสุดอัตโนมัติ
- **แจ้งเตือนอัจฉริยะ** — บอร์ดหลุดการเชื่อมต่อ, เซนเซอร์ไม่ส่งค่า, เกรดตกเป็น C, กระแทกสะสมสูงผิดปกติ พร้อมประวัติการแจ้งเตือนย้อนหลัง
- **กราฟแนวโน้ม** — อุณหภูมิ/ความชื้น และจำนวนวันที่เหลือ แสดงเป็นกราฟเส้นแบบสด
- **ตัวกรองข้อมูลขยะ (Data Quality)** — ตัดข้อมูลที่ parse ไม่สมบูรณ์หรือค่าผิดปกติออกอัตโนมัติ ทั้งตอนอ่านจากพอร์ตและตอนโหลดจากไฟล์ CSV เก่า พร้อมแถบวัดคุณภาพข้อมูลของแต่ละล็อต
- **บันทึกข้อมูลถาวร** — เซฟลง CSV ทุกแถวทันที (กันข้อมูลหายหากโปรแกรมปิดกะทันหัน) และซิงก์ขึ้น Google Sheets แบบ background ได้ถ้าตั้งค่าไว้
- **ใช้งานได้แม้ไม่มีอินเทอร์เน็ต** — รันในเครื่อง เปิดผ่านเบราว์เซอร์ในวง LAN เดียวกัน (มือถือก็เปิดดูได้)

## 🧠 หลักการทำงาน

```
[ micro:bit + เซนเซอร์ ]  --USB Serial-->  [ vegtrack_dashboard.py ]  --HTTP-->  [ เบราว์เซอร์ ]
   (T, H, W, Days,                              │
    Grade, Impact, Event)                       ├─→ บันทึกลง CSV
                                                 └─→ ซิงก์ขึ้น Google Sheets (ถ้าตั้งค่า)
```

micro:bit อ่านค่าจากเซนเซอร์ (DHT สำหรับอุณหภูมิ/ความชื้น, โหลดเซลล์สำหรับน้ำหนัก, และตรวจจับแรงกระแทก) แล้วส่งข้อความรูปแบบ `key=value` ออกทาง Serial เช่น

```
T=28.7 H=60.3 W=92.5 Days=2.1 Grade=A Impact=0 Event=still
```

ฝั่งโปรแกรม Python จะอ่านค่าเหล่านี้ กรองข้อมูลที่ผิดปกติทิ้ง แล้วอัปเดตสถานะของแต่ละล็อตแบบเรียลไทม์:

| ฟิลด์ | ความหมาย |
|---|---|
| `T` | อุณหภูมิ (°C) |
| `H` | ความชื้นสัมพัทธ์ (%) |
| `W` | น้ำหนักคงเหลือเทียบกับตอนเริ่มต้น (%) — บอกระดับการคายน้ำ/เหี่ยว |
| `Days` | จำนวนวันโดยประมาณที่เหลือก่อนผักจะเสีย |
| `Grade` | เกรดคุณภาพปัจจุบัน — `A` ขายตามลำดับปกติ, `B` ควรเร่งขาย, `C` ต้องขายวันนี้ |
| `Impact` | จำนวนครั้งสะสมที่ถูกกระแทก/สั่นระหว่างขนส่ง |
| `Event` | สถานะล่าสุด เช่น นิ่ง (`still`) หรือถูกกระแทก (`shock`) |

## 📦 การติดตั้ง

ต้องมี Python 3 และไลบรารี `pyserial`:

```bash
pip install pyserial
```

ถ้าต้องการซิงก์ข้อมูลขึ้น Google Sheets ด้วย ให้ติดตั้งเพิ่ม:

```bash
pip install gspread
```

## 🚀 วิธีใช้งาน

### 1) แดชบอร์ดแบบเต็มรูปแบบ (แนะนำ)

```bash
python vegtrack_dashboard.py
```

- โปรแกรมจะค้นหาพอร์ตของ micro:bit ให้อัตโนมัติ (ถ้าหาไม่เจอจะให้พิมพ์ชื่อพอร์ตเอง)
- เมื่อพร้อมแล้ว โปรแกรมจะแสดงลิงก์ให้เปิดในเบราว์เซอร์ เช่น

  ```
  http://localhost:8000
  http://<ip เครื่องนี้>:8000   (เปิดจากมือถือ/เครื่องอื่นในวง LAN เดียวกัน)
  ```

- กด `Ctrl+C` เพื่อหยุดการทำงาน (ข้อมูลจะถูกบันทึกและปิดไฟล์อย่างปลอดภัยเสมอ)

**เพิ่มล็อตเพิ่มเติม** ได้โดยแก้ตัวแปร `LOTS` ในไฟล์ `vegtrack_dashboard.py` เช่น

```python
LOTS = [
    {"name": "ล็อต 1", "port": "", "csv": "vegtrack_log.csv"},
    {"name": "ล็อต 2", "port": "", "csv": "vegtrack_log_2.csv"},
]
```

ปล่อย `"port": ""` ไว้เพื่อให้ระบบหาพอร์ตให้อัตโนมัติ

### 2) โปรแกรม Logger แบบ command line (เบากว่า)

ใช้สำหรับดู log สดบนเทอร์มินัลอย่างเดียว โดยไม่เปิดเว็บแดชบอร์ด:

```bash
python vegtrack_logger.py
```

> ⚠️ ห้ามเปิดโปรแกรมอื่นที่จับพอร์ต Serial เดียวกันพร้อมกัน (เช่น Termite) ไม่งั้นจะแย่ง COM port กัน

## 🔗 การเชื่อมต่อ Google Sheets (ไม่บังคับ)

1. เตรียมไฟล์ credentials สำหรับ Google OAuth ชื่อ `credentials.json` ไว้ในโฟลเดอร์โปรเจกต์
2. ตั้งค่า `GSHEET_SHEET_ID` ในไฟล์ `vegtrack_dashboard.py` ให้เป็น ID ของ Google Sheet ปลายทาง
3. ระบบจะสร้าง worksheet แยกตามชื่อล็อตให้อัตโนมัติ และ append ข้อมูลใหม่แบบ background ทุกครั้งที่มีข้อมูลเข้า

หากไม่ตั้งค่าไว้ ระบบจะข้ามส่วนนี้ไปเฉยๆ และยังบันทึกลง CSV ตามปกติ

## 🛠️ เทคโนโลยีที่ใช้

- **Python 3** — อ่านค่าจาก Serial, ประมวลผล, เสิร์ฟเว็บด้วย `http.server` (ไม่ต้องพึ่ง framework ภายนอก)
- **micro:bit** — ตัวรับสัญญาณเซนเซอร์และส่งข้อมูลผ่าน USB Serial
- **HTML/CSS/JavaScript (vanilla)** — หน้าแดชบอร์ด ธีมสว่าง ฟอนต์ Noto Sans Thai, กราฟวาดด้วย SVG ล้วนๆ ไม่ใช้ไลบรารีภายนอก
- **Google Sheets API** (ผ่าน `gspread`) — สำรองข้อมูลขึ้นคลาวด์แบบไม่บังคับ
