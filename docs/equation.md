# ที่มาของสมการ

สมการทำนายอายุการเก็บรักษาไม่ได้มาจากการคาดเดา แต่สอบเทียบจากข้อมูลการทดลองจริง
(ผัก 8 มัด, 4 กลุ่ม, ชั่งน้ำหนักและให้คะแนนความสดทุกวัน ต่อเนื่อง 4 วัน)

## ขั้นที่ 1 — เกณฑ์ "ผักเสีย"

หาว่า ณ วันที่คะแนนความสดเฉลี่ย ≤ 2 (นิยามว่าเสีย) แต่ละมัดเหลือน้ำหนักกี่ % ของวันแรก

| มัด | กลุ่ม | วันที่เสีย | % น้ำหนักคงเหลือ |
|---|---|---|---|
| A1 | ปกติ | 3 | 81.8% |
| A2 | ปกติ | 4 | 80.4% |
| C1 | กระแทก | 4 | 72.1% |
| C2 | กระแทก | 4 | 81.7% |
| D1 | โดนทับ | 4 | 81.0% |
| D2 | โดนทับ | 3 | 79.0% |

ค่าเกาะกลุ่มที่ 79–82% → ใช้เป็นค่าคงที่: **ผักเสียเมื่อน้ำหนักคงเหลือ ≤ 80%**

## ขั้นที่ 2 — อัตราการสูญเสียน้ำหนักตามอุณหภูมิ

| กลุ่ม | อุณหภูมิเฉลี่ย | อัตราลด (%/วัน) |
|---|---|---|
| A, C, D (ในห้อง) | 29.93 °C | 9.26 |
| B (ตู้เย็น) | 8.86 °C | 5.71 |

ลากเส้นตรงเชื่อม 2 จุด:

```
slope (m)     = (9.26 - 5.71) / (29.93 - 8.86) = 0.1685
intercept (c) = 9.26 - (0.1685 x 29.93)        = 4.2172

อัตราการสูญเสียน้ำหนัก (%/วัน) = 0.1685 x อุณหภูมิ + 4.2172
```

## ขั้นที่ 3 — สมการอายุที่เหลือ

```
อายุที่เหลือ (วัน) = (% น้ำหนักคงเหลือ - 80) / อัตราการสูญเสียน้ำหนัก
```

ตัวอย่าง: ผักที่ 30°C น้ำหนักคงเหลือ 95%
```
rate = 0.1685 x 30 + 4.2172 = 9.27 %/วัน
days = (95 - 80) / 9.27      = 1.62 วัน  -->  เกรด A
```

## บนบอร์ด (เมื่อชั่งน้ำหนักไม่ได้)

micro:bit ไม่มีเซนเซอร์ชั่งน้ำหนัก จึงประมาณน้ำหนักที่หายไปแบบสะสมจากอุณหภูมิที่วัดได้ ทุก 4 วินาที:

```
loss = rate x (4 / 86400)        # แปลง %/วัน เป็น % ต่อ 4 วินาที
pct_weight -= loss
days = (pct_weight - 80) / rate
grade = A ถ้า days>=1.5, B ถ้า >=0.5, มิฉะนั้น C
```

## ความแม่นยำ (Leave-One-Out Cross Validation)

สร้างสมการจาก 7 มัด ทำนายมัดที่ 8 ที่ไม่ได้ใช้สร้างสมการ วนครบทุกมัด

**MAE = 0.25 วัน** (รายงานเป็น "จากชุดข้อมูลนี้ MAE = 0.25 วัน" — ไม่ใช่ "แม่นยำ 0.25 วัน" เพราะฐานตัวอย่างยังเล็ก)

## ทำไมการกระแทกไม่เข้าสมการ

ตั้งสมมติฐานไว้ว่ากระแทกทำให้เสียเร็วขึ้น แต่ผลจริงไม่สนับสนุน:

- C1/C2 (กระแทก 10 ครั้ง/วัน) ไม่ได้เสียเร็วกว่ากลุ่มควบคุมเลยแม้แต่มัดเดียว
- Penalty ที่คำนวณได้ = **-0.0167** (ติดลบ) ซึ่งแปลว่า "ยิ่งกระแทกยิ่งอยู่ได้นาน" ไม่สมเหตุสมผลทางชีววิทยา

จึงไม่นำตัวแปรกระแทกเข้าสมการ แต่ยังคงนับด้วย Edge AI และแสดงเป็น "ดัชนีความบอบช้ำ" แยกต่างหากให้ผู้ขายดูประกอบการตัดสินใจ
